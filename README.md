# task-reminder

PWA personal de tareas periódicas con modos (Normal, Verano…): se reinician solas cada semana, mes, trimestre, semestre y año; muestra cuándo se hizo cada una; funciona sin conexión y guarda los datos solo en tu dispositivo.

- **iPhone**: abre la URL de GitHub Pages en Safari → Compartir → «Añadir a pantalla de inicio».
- **PC**: se lanza desde My Tools (`abrir-task-reminder.ps1`) o `npm start` → http://localhost:8095/
- Reglas y comandos: `CLAUDE.md` · Decisiones: `docs/adr/` · Datos y migraciones: `docs/datos-y-migraciones.md`
